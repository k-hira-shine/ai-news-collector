# Apify コスト比較ログ

## 2026-06-10（4施策の実装前基準）

### 実績
- 前請求サイクルの最終推定: **$47.91**
- 通常運用の比較期間: 2026-06-05〜2026-06-09
- 比較期間平均: **$0.7823/日**
- 月額換算: **$23.47**
- 内訳: News $4.19 / Money・SNS $13.87 / Buzz $5.42

### 採用する削減施策
1. SNS広域検索を3日に1回にし、検索クエリを整理する。
2. Money/SNSのアカウント取得を統合し、前回取得以降の差分収集にする。
3. Buzzを週3回にする。
4. News夕方便を検索と重要公式アカウント中心の軽量収集にする。

### 実装後の見込み
- 中心見込み: **$0.332/日、$9.96/月**
- 確認レンジ: **$8〜12/月**
- 基準比の見込み削減率: **57.6%**

見込みは施策間の重複を調整済み。Money/SNSの2施策は単純合算しない。
実装後は `data/cost_tracking.json` を各定期実行で更新し、完了済み7日間の
移動平均、月額換算、取得件数を確認する。詳細な前提は
`data/cost_reduction_plan.json` に記録する。

実装日当日の既存実行コストは比較対象から除外し、翌日の完了データから
削減後の移動平均を開始する。
